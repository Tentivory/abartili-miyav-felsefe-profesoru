# Abartılı Miyav Felsefe Profesörü

**Dünyanın En Ciddi Miyav Çeviri Sistemi**

Bu repository, kedilerin miyavlarını derin, anlamsız ama aşırı ciddi görünen felsefi Türkçe cümlelere çeviren bilimsel bir araçtır. Gerçekten çalışır. Kedi gerekmez ama olursa daha otantik olur.

## Neden Bu Proje?

Çünkü kediler her şeyi bilir. Biz sadece çeviriyoruz. Bilim henüz bunu kabul etmedi ama yakında edecek. Bu arada siz miyavınızı girin, biz de size evrenin sırrını (ya da köfte yasinı) söyleyelim.

## Kurulum ve Kullanım

1. Python 3 yüklü olsun (kediniz varsa o da yeterli).
2. Kodu çalıştırın:
   ```bash
   python miyav_profesoru.py
   ```
3. Miyavınızı yazın. Örnek: `miyav miyav`
4. Derin analiz alın.
5. Hayatınızı sorgulayın.

## Özellikler

- Rastgele felsefi çeviriler (her seferinde farklı saçmalık)
- Hata kontrolü (miyav olmayan girdileri reddeder, çok bilimsel)
- Sonsuz döngü (kedi gibi)
- Gerçekten çalışır (test edildi, kedi onayladı)

## Uyarı

Bu kodu çalıştırmadan önce çay için. Miyavları fazla ciddiye almayın ama alın. Felsefe tehlikelidir.
